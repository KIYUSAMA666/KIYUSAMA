# フワ（Muse）用の受け渡し箱（fuwa inbox）

ここは、キラ（Claude）がフワに渡す「仕事」を置く場所です。フワは自分のブラウザでこのページを読めます。
キラ→GitHub→フワ の一方通行。フワからの返事は、親父がキラに伝えます。

## フワの読み方
1. `INDEX.md` を開く。いちばん上の「未着手」の仕事を1つ選ぶ。
2. その仕事のファイル（`jobs/日付_名前.md`）を開いて、書いてある通りに作る。
3. 作ったものを親父に見せる。親父がOKを出したら投稿する。勝手に投稿しない。
4. できなかった部分は、正直にそう言う。勝手に作り直して黙って出さない。

## 共通の決まり
`VOICE.md` に書いてある。毎回、仕事の前に読む。
